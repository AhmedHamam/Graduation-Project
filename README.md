# 🎓 Graduation Project — Patient Booking

A C# WinForms application for patient booking at a medical facility: staff log in, book patient visits and look up patients through a search screen.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![.NET Framework](https://img.shields.io/badge/.NET%20Framework-WinForms-5C2D91?style=flat-square&logo=dotnet&logoColor=white)
![SQL Server](https://img.shields.io/badge/SQL%20Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white)

## ✨ Features

- **Login** — user authentication before accessing the system
- **Main dashboard** — central navigation to all modules
- **Patient booking** — create bookings / visits for patients
- **Patient search engine** — quickly find patients and their data

## 🧱 Main screens

| Form | Purpose |
|---|---|
| `Frm_Login` | Sign in |
| `Frm_Main` | Main menu |
| `Frm_Patient_Booking` | Book a patient visit |
| `Frm_Patients_search_engine` | Search patients |

## 🚀 Getting started

1. Open `Graduation Project/Graduation Project.sln` in Visual Studio.
2. Update the connection string in `App.config` to point to your SQL Server.
3. Build and run (F5).
